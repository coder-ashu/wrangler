🛠️ Project Build and Debug Prompts
==================================

⏱️ Build Execution and Skipping Checks
--------------------------------------

- How do I rebuild the project from the root?
  mvn clean install -Dcheckstyle.skip=true

- I want to skip the Checkstyle check during Maven build.
  → Use -Dcheckstyle.skip=true with your Maven command.

- I made changes to pom.xml, what should I do next?
  → Run mvn clean install from the root directory.


📂 File System and Compilation Errors
-------------------------------------

- Where is the target directory and how do I delete it?
  → Located at /target inside each module. Delete it manually or run mvn clean.

- Why is my project failing to compile after deleting files?
  → Likely because compiled .class files were deleted or source .java files were incomplete.

- How do I rebuild the target directory?
  → Run mvn clean install or mvn compile from the module root.

- Which file should I restore from the GitHub repo to fix missing classes?
  → Restore missing .java files like AvroSchemaGlossary.java, then rebuild.


🧪 Testing Commands
-------------------

- How do I run a specific test file and skip Checkstyle?
  mvn -Dtest=YourTestClassName test -Dcheckstyle.skip=true

- How do I skip all Checkstyle validations but still run tests?
  mvn test -Dcheckstyle.skip=true


🌐 Git Configuration
--------------------

- How do I change the origin of a GitHub repo?
  git remote set-url origin https://github.com/username/new-repo.git
